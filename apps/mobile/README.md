# Convo Glasses Mobile App

Companion mobile app built with Expo and React Native.

## Tabs (Target in M4)
1. **About Me**: Profile headline, facts grouped by kind, resume upload.
2. **Coach**: Chat with the guide agent (Discover & Prep modes).
3. **History**: Browsable conversation transcripts and suggestion ratings.
4. **Live**: Real-time session launcher and glasses pairing state.
